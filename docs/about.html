About the project

Learn together. Share knowledge.

NoteShareHub is a student notes sharing platform with a PHP/MySQL application and a separate static preview.

Two different versions

The full application uses PHP, MySQL, user sessions, database-backed note records, and server-side PDF uploads. GitHub Pages cannot execute PHP or connect to its MySQL database.

This docs/ site is a static UI demonstration made from HTML, CSS, and browser JavaScript. It has no authentication, server storage, database access, or working account actions.

Static demo features

  • Browse sample note cards and filter them locally.
  • Preview upload, login, and registration forms.
  • Responsive layouts reuse the project's CSS and logo.
  • No submitted data is sent to a server.
